# Contra Studio development

Start with `docs/development-map.md`. Read one relevant contract, adapter and test
family at a time. Use `node scripts/inspect-source.mjs <id> --couples=3` for compact
offline evidence. Never dump generated Ready archives or the one-line catalogue.

New adapters consume actual carried roots/facing, stable actors, partner/current
neighbor maps, raw contacts, source clock and epoch. Return actual exits. Select
by local figure/successor and state, never title/source ID or whole dance signature.
Only reached source endpoints may rebind; rebinding cannot move bodies. Preserve
guarded legacy routes and distinguish strict-carried from established-acquisition.

Prioritize whole-dance paths, counts, relationships, progression and finite ends.
Appearance does not determine role. Correct buzzstep remains deferred. Separate
source interpretation, root geometry, hand reach and actual GPU/audio evidence.

Use subagents with distinct file ownership for independent work. The lead owns
integration and periodically reports concrete results while continuing routine
work autonomously. Local deployment is authorized. Public hosting targets GitHub
Pages; do not overwrite the old private hosted site. Original code is MIT; no
GPL-family implementation dependencies. Preserve third-party source provenance.

Run focused tests during iteration, plus Ready regression for admission changes.
Report exact scope, failed checks, and unrun build/GPU/audio stages. Update the
development map checkpoint instead of creating repetitive handoff narratives.
Do not regenerate Ready archives solely for inspection. Never adjust source
counts or relax motion limits merely to make a dance compile.
