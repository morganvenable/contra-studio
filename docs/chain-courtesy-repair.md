The changed acquisition/release regression windows keep unrelated arms, torso, head, legs and active own-arm/torso margins positive. The smallest sampled associated upper/elbow margin is 5.300 mm. These categories remain separately measured and bounded rather than hiding every arm belonging to a joined pair. Sampled mesh checks are regression evidence, not a continuous collision certificate.
