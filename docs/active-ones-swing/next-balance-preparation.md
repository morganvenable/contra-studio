# Released active swing to the next neighbor balance

The explicit terminal figure modifier `preparation: 'next-neighbor-balance'`
selects a public stance composition after the current-ones swing releases its
old partner frame. It is available only for an eight-count terminal current-ones
swing with the next-neighbor exit and a next-cycle unhanded neighbor balance (4 counts)
immediately followed by the same-neighbor swing. It does not select by source
identity, title, or a complete figure list.

The existing active-swing geometry and fixed-root variant are retained. A
fixed-root terminal active swing is rejected if the next opening would trigger
paired-balance stance preparation. This prevents an accepted archive from
promising fixed waiting roots while a later presentation wrapper moves them.

## Counted, visible movement

The old swing frame has completely released at local count 6.5 (source count 62.5 in 2490).
The preparation weight is zero through that count and eases over the final 1.5
source counts. The ordinary opening balance target provides exact reciprocal
next-neighbor identities and offsets. This includes a waiting couple only when
it actually reenters a next group; actors lacking a next neighbor have no target.
No event or relationship rebind occurs early. The source event remains at count 64.

As with the existing balance stance, future joined contacts acquire only after
preparation weight exceeds 0.65 and only for unoccupied anatomical hands. Actual
2490 samples first show them around count 63.53, after the old frame is gone.

The separate removable source choice is
`activeSwing: { inactive: 'prepare-next-balance' }`. It discloses the modeled
preparation for all actors with next neighbors, including current twos and newly
available end waiters. The omitted source facing remains its own review choice.
236 keeps the original `wait-in-place` choice and path.

## Inspectable coordinate layers

`sample` returns the actual prepared roots and contacts. `formationSample`
returns the unchanged formation motion before the public balance preparation.
The compiled `balancePreparations` records name the producing and target figure,
the exact source interval, the next-cycle actual-neighbor binding, and this
coordinate-layer distinction. Local sequence proofs continue to describe their
formation layer; they do not certify fixed public roots during this preparation.
