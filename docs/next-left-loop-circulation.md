20 October 2026. Bounded investigation of the eight left-loop sources identified
in wave-generalization.md. No new playback admission or runtime change.

## Smallest reusable operation

Add an explicitly left-handed four-count box-circulation operation to the existing
measured-state binding/kernel, retaining the four-count balance as a separate
operation or explicit 4+4 combination. Eight retained sources contain ten literal
left-loop rows: 965, 966, 1846, 1856, 2033, 2329, 2916, 3056. Both crossing roles
occur. This is a shared operation with ample source evidence, but no source is
unblocked by that change alone.

The binding currently rejects anything but right loops: an outward actor must
occupy local row sign `-side`, travels to `(x,-z)`, and rotates by minus pi. A left
loop instead requires the opposite row/facing compatibility and plus-pi turn.
The crosser still travels to `(-x,z)` with room-facing preserved. Validate actual
vacant destination stations and bijection; changing a string or yaw sign alone
is insufficient. A mirrored kernel can reuse the proven trajectory and budgets
if it consistently reflects positions, facing, wave hands, handed turns and
coordinate frame, then maps outputs back. Stable actor IDs and all relationship
maps remain unchanged. Do not mirror choreography roles or invent a progression.

`full-long-wave.ts` currently assumes right-hand box segments and left-hand seams.
Left-handed circulation needs the actual opposite graph where applicable, with
explicit adjacent seam hands retained. Do not fit it into four-actor boundaries
by discarding outside contacts. Box membership is independent of the held graph:
after changing loop direction, the supplied same four actors might no longer
form the required circulation box. Reject that input; a global owner must identify
new box memberships at a reached endpoint without moving or rebinding people.

1. Independently specify mirrored station/hand oracles for both initiating roles.
2. Add left-handed binding and four-count kernel with explicit direction, while
   keeping old right-loop default/guards intact. Test translation, rotated frames,
   sparse IDs, wrong-facing rejection, wrong destination, stale maps and ownership.
3. Extend carried full-wave operation and seam graphs only with whole-set collision
   evidence including waiters. Test repeated left loops and mixed directions with
   explicitly valid box memberships; do not assume a fixed partition works.
4. Keep source admission closed until an actual producer reaches the graph and a
   complete source path proves exit, progression, waiting, reentry and closure.

to another Ready dance. For near-term whole-dance payoff, finish the already
