# Separate forward and return-rollaway source rows

`source-lines-rollaway.ts` recognizes adjacent unmarked four-count long-lines
forward and four-count role-initiated neighbor rollaway with a half sashay.
Optional literal return and direction qualifiers are consumed completely.
Shadow, partner, missing-half-sashay, extra-movement and differently counted
clauses remain outside this source contract.

An explicit `linesRollaway: {phase: 'return', direction: ...}` choice belongs to
the forward row. It interprets the rollaway as occurring during the return and
names the lateral direction. An explicit source direction cannot be overridden.
The two original source rows and their counts remain unchanged; their compound
metadata identifies the single eight-count execution figure. The old standalone
rollaway choice is rejected when it would duplicate this compound interpretation.

The shared neighbor adapter consumes actual actor roots, roles, partner and
neighbor maps, source beat and epoch. It rejects incoming holds. The existing
four-forward/four-return kernel measures the actual same-side pair geometry;
initial headings acquire the inward pair facing during the first 1.5 advance
counts, with no extra count or stationary preparation. New hands acquire after
the heading turn over 0.75 counts. Return geometry, full rolling rotation and
half sashay remain the existing kernel's. These are schematic facing/contact
conventions. Existing combined partner-source routing remains unchanged.

Source2243 requires the lark-initiated robin roll left to right and terminal
neighbor chain. Source2322 requires the robin-initiated lark roll right to left
and earlier partner chain. Alternative directions or chain receivers reject
their actual geometry. Tests preserve removable choices, source-row ownership,
complete three/four-couple periods, all couple encounters, named contacts,
strict carried exchanges, seams, roots/facing/contact closure and an unrelated
rotated/translated opaque-ID frame. Source identity/title do not select motion.
