# Shared carried role-first heys

Implemented 20 October 2026. The shared encounter planner resolves actual partner
and current-neighbor maps into four half-hey or eight full-hey pass layers. The
motion adapter consumes measured released sideline state and returns actual
station ownership: reversed for a half hey, unchanged for a full hey. Both modes
face across at exit. Neither reads a successor, source ID, title or whole sequence.

## Scope

- Explicit first role, opposite center/end shoulders and partner/neighbor side pairs.
- Eight counts for half, sixteen for full; no progression within either figure.
- Released incoming hands, measured paired sidelines and compatible role order.
- Stable actor IDs, partner/current-neighbor maps and epoch; no binding changes.
- Exact incoming station coordinates determine exit positions, including unequal
  offsets. No mirrored-root shortcut or successor-specific spacing normalization.
- New half exit is an explicit removable source choice: opposite-slots-facing-across.
  Existing prepared balance/swing/gyre and progression routes remain guarded.
- Neutral Becket half-hey choices require the separately validated carried slice wrapper.
  This does not implement diagonal, ricochet, pair-first or partial-encounter heys.

The boundary carries roots/facing/contacts, not velocity. The existing connector
uses zero endpoint velocity; this is not a claim of carried momentum or anatomically
verified footwork. Legacy successor-facing acquisition remains labeled separately
from the new strict-carried hey.

## Timing and motion evidence

Half-hey shoulder gates occur at 17/8, 43/12, 121/24 and 13/2 counts. This allows
2 1/8 counts to reach the first encounter, three equal 35/24-count intervals,
and 1 1/2 counts to finish the last passage facing across. These are disclosed
animation subdivisions within eight source counts, not authored timestamps.
One schedule supports tested compact and full-width entries without branching on
a source or following figure. Existing continuous clearance, speed (1.3) and yaw
rate (4) limits remain enforced. Full mode retains its previous gates and 1.35
speed budget. Unsupported geometry still fails closed.
