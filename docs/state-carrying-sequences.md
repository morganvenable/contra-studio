# State-carrying ordinary sequences

This first shared-sequencer slice admits repeated balanced square-through units from their measured incoming state. Motion admission has no dance title, source ID, complete row list, or whole-figure-list signature. The current source proof uses Saturday Night Fever (896), Friday Night Fever (146), and When It Chains It Pours (2364), plus exact preservation of Fair and Square (3496).

## One boundary, one registry

`SequenceBoundary` owns the source clock, relationship epoch, stable actors and persistent couples, explicit partner/current-neighbor maps, actual roots/facing, and raw held contacts. The common capture reuses the audited plain-data snapshot helper. Discrete identities and clocks compare exactly; geometric/contact values use a small numerical tolerance. Cross-group contacts are rejected rather than dropped.

`sequence-registry.ts` chooses a figure adapter using the figure and its immediate successor. The new chain-to-square and square adapters consume complete incoming boundaries. A nonterminal square returns partner-facing roots and released hands without selecting its next figure: the next adapter must accept that actual state. A chain can additionally declare the source's partner-right-hand offer, producing a compact held boundary which the following balance genuinely consumes. A literal square-through-four row is two repeated two-hand units, with source counts retained and only its final declared event advancing the epoch.

Established figure adapters remain in the common sequence carrier with their existing paths and within-figure hand acquisition. Their recorded proof includes the untouched incoming contacts, actual entry/exit contacts, and `contactPolicy: established-acquisition`. This slice checks their root, identity and clock continuity, but does not claim to have migrated their legacy contact acquisition to the new strict contract. New registry adapters are labeled `strict-carried` and compare the complete incoming contact graph.

## Source event and finite line

`state-sequence.ts` owns the separate, source-bound one-place terminal event. It validates the retained snapshot and event placement, then checks actual finite ranks against the shared directed-couple slot binder. The ordinary engine carries actual endpoints into the next repeat; no geometry is reset by the event. The complete period returns every actor, including waiting couples, to the initial roots/facing. Existing wait-out and next-opening balance preparation remain within their source counts.

An old typed terminal-only declaration without the new event contract retains its existing guarded legacy route; an explicit event, including a malformed one, cannot fall back.

For ordinary improper sources using the shared role do-si-do or neutral hey,
an explicit `end-of-cycle` interpretation can also supply this event when the
source contains no progression markers. Its evidence is labeled
`reviewed-interpretation` and binds the exact snapshot and URL. Only a cloned
execution figure receives the terminal marker; retained source rows and resolved
row figures stay unmarked. Removing the choice blocks admission. The unchanged
finite compiler must prove the actual one-place endpoint permutation, so the
choice cannot add travel or waive an unsuitable endpoint. This does not migrate
other legacy endpoint-review routes or admit a source to the Ready library.

The first slice is restricted to ordinary improper finite lines and one terminal progression. This is a formation/event capability, not a per-dance compiler. More event placements can extend that common contract later.

## Bounded evidence

- Central capture/ownership/clock/held-contact tests once at the shared boundary.
- The same local adapters accept chain → square → long-lines → square and an alternate partner balance; displaced roots, wrong epochs and unexpected holds reject.
- The three actual sources run complete representative odd/even periods (3 and 4 couples), checking source intervals, literal named right/left gates, persistent partners, waits, re-entry and physical closure. Cheap directed-slot coverage checks 2–12 couples.
- Independently prepared legacy/current 3496 samples match in all frame fields over representative complete periods.
- Source archives, removable choices and actual offline Ready playback remain release gates. Detailed limb refinement is not part of this sequencing slice.
