source counts, released hands and an explicit progressed-neighbors exit. Each
actor makes a full return before an additional half exchange into their actual
old neighbor's station. Partner IDs, neighbor IDs and relationship epoch remain
unchanged. A separate source event owns progression.

The .45-by-.9 ellipse and arc-length pacing match the existing ten-count
progressing do-si-do kernel at equal normalized progress. That old kernel is
unchanged. Incoming facing settles during the first count while roots already
move; facing is fixed for the rest of the eight-count traversal.

`measured-ingress.json` retains the actual count-56 raw circle producer for 831
and 3081, including numerical residue and source provenance. The focused test
reconstructs both producers with their genuine immediate successor type rather
than using the yaw of a truncated preview.

(right). The full own-station return is 61.046666666; the additional half

metadata. The local adapter performs no future-neighbor lookup, stance offset,
hand acquisition or local epoch change.
